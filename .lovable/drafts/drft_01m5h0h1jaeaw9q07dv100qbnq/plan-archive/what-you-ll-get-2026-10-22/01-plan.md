## What you'll get

**1. Full profile editing in the console**

- Organizers can edit every field: name, email, phone, identifier code, role on card, submission ID, institution.
- Each profile can hold a **second email**. Whoever signs in with either email lands on the same profile, pass and network. The desk can add the second email when a guest has signed in with the wrong address. No sign-out needed.
- If that guest already has a stray Visitor profile from the wrong email, the desk sees a **Merge** button. It moves their connections, bookmarks and claims to the correct profile, then removes the stray one.
- Changing an identifier code shows a warning first: "Printed cards and QRs with the old code stop working." It also offers to re-download the QR.

**2. Issues panel**
A "Needs attention" strip above the People table, with a filter for each kind of issue:

- The same email used on two profiles (as a main email or a second email). The database also blocks this.
- Possible duplicates: very similar names at the same institution, or the same phone number.
- Placeholder emails (made-up addresses) on profiles that will get printed cards.
- Profiles nobody has signed into yet, and sign-ins with no matching profile.
- Codes that don't follow the WMC-XXXX pattern.
